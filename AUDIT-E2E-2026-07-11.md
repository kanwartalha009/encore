# Encore — end-to-end audit + fix pack (2026‑07‑11)

> Scope: "does Encore work end‑to‑end for any Shopify store + theme; any dummy data or
> missing features?" Method: static analysis (grep/tsc) over `app/`, `extensions/`,
> `shopify.app.toml`. Every claim verified by a command run now. Build (`npm run build`)
> is Mac‑only (rollup `linux-arm64` native missing here).

## Summary

The core pipeline (auth, webhooks, GDPR, storefront app blocks, billing, Nova outbox)
was sound. The audit found the **admin product/collection/market pickers were backed by
a demo catalog** (`app/lib/demoProducts.ts`), **COLLECTION storefront matching was a
stub**, and **three extension URLs were hardcoded to localhost**. All code‑level items
are now fixed; the URL items are deploy‑config (documented in `DEPLOY-CHECKLIST.md`).

## Confirmed working end‑to‑end (verified)

- `tsc --noEmit` = **0 errors** after the fix pack.
- Auth (token exchange), webhooks (`app/uninstalled`, `scopes_update`, `products/update`,
  `inventory_levels/update`, `app_subscriptions/update`), and all 3 GDPR compliance webhooks registered.
- `orders/*` correctly **commented** in `shopify.app.toml` until PCD approval.
- Storefront blocks are OS 2.0 **app blocks** (preorder / notify‑me / low‑stock on the
  product template + app‑embed) → work on any OS 2.0 theme via the theme editor. Vintage
  (non‑OS2.0) themes need manual placement (standard for the category).
- Preorder **ALL** mode, **SPECIFIC** mode (real GIDs from the picker/wizard), and now
  **COLLECTION** mode all resolve on the storefront.
- Markets: live Admin fetch with labelled demo fallback (`usingDemo`).
- Nova calls go through the durable outbox; billing path intact.

## Known limitations (design, not bugs)

- Collection **picker** lists the first 100 collections; product picker uses Shopify's
  native paginated resource picker (no limit).
- COLLECTION storefront membership is checked live per request (memoized per request).
  Fine for launch volume; a cached/snapshot path can be added if hot products need it.
